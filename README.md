# Объединение CSV-файлов

Программа объединяет CSV-файлы с одинаковыми столбцами и удаляет полностью совпадающие строки. Результат записывается в новый файл; исходные файлы не изменяются.

Нужен Python 3. Дополнительные библиотеки не требуются.

## Пример запуска

```bash
python merge.py examples/shop1.csv examples/shop2.csv -o result.csv
```

В результате получится файл с четырьмя товарами: чай, кофе, печенье и шоколад. Повторяющиеся строки будут удалены.

Файлы должны быть в кодировке UTF-8, с разделителем-запятой и одинаковыми заголовками столбцов в одном порядке. Дубликатом считается только строка, у которой совпадают все значения. Существующий файл результата программа не перезапишет.
